Hermes Paljaya

Asisten otomatisasi pribadi untuk pekerjaan administrasi proyek konstruksi.

Identitas aplikasi: Hermes Paljaya adalah aplikasi pribadi milik pengembangnya untuk otomatisasi administrasi proyek konstruksi. Aplikasi ini dipakai satu orang — pembuatnya sendiri. Tidak ditawarkan ke publik, tidak menerima pendaftaran pengguna, dan tidak memiliki server yang menyimpan data siapa pun.

Apa ini

Hermes Paljaya adalah agen otomatisasi yang berjalan di komputer pribadi pemiliknya. Tugasnya membantu pekerjaan administrasi proyek konstruksi: menyusun berita acara pembayaran, menjaga penomoran surat, menghitung volume dan nilai pekerjaan, serta merapikan dokumen proyek.

Kenapa perlu akses Google

Seluruh data kerjanya tersimpan di Google Sheets dan Google Drive milik pemiliknya sendiri. Aplikasi ini membaca dan menulis ke berkas-berkas itu atas nama pemiliknya, lewat izin yang diberikan sekali melalui layar persetujuan Google.

  • Sheets & Docs — membaca data proyek dan menghasilkan draft dokumen
  • Drive — membuka, menyimpan, dan merapikan berkas proyek
  • Gmail & Calendar — menyusun draft surat pengantar dan mencatat tenggat
  • Contacts — membantu mengisi nama dan alamat tujuan surat

Setiap izin diminta hanya untuk fungsi yang dijelaskan di Kebijakan Privasi. Data Google dipakai untuk menyediakan fungsi tersebut, bukan untuk iklan, profiling, analitik, atau pelatihan model.

Data kamu

Tidak ada. Aplikasi ini tidak punya pengguna lain selain pemiliknya, tidak mengumpulkan data dari siapa pun, dan tidak mengirim apa pun ke pihak ketiga. Rinciannya ada di Kebijakan Privasi.

In English

Hermes Paljaya is a personal automation assistant that runs on its owner's own computer. It helps with construction-project paperwork — payment certificates, letter numbering, quantity take-offs — using data that already lives in the owner's own Google Sheets and Drive. It is used by exactly one person, is not offered to the public, accepts no user sign-ups, and operates no server that stores anyone's data. See the Privacy Policy for details.
