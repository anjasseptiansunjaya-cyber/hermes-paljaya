Kebijakan Privasi

Hermes Paljaya · berlaku sejak 14 September 2026

Aplikasi ini dipakai satu orang saja — pemiliknya sendiri. Tidak ada pendaftaran pengguna, tidak ada server yang menampung data, dan tidak ada data milik orang lain yang diproses. Yang diakses hanyalah akun Google milik pemilik aplikasi itu sendiri, atas persetujuannya sendiri.

Pengembang dan kontak: Hermes Paljaya · anjas.septian.sunjaya@gmail.com. Alamat ini sama dengan kontak pengembang pada Google Cloud OAuth consent screen.

1. Data apa yang diakses

Hermes Paljaya meminta izin berikut lewat layar persetujuan Google. Setiap izin dipakai hanya untuk keperluan yang disebut di sini:

IzinDipakai untuk
https://www.googleapis.com/auth/spreadsheetsMembaca dan menulis data proyek di Google Sheets milik pemilik (nomor surat, volume pekerjaan, nilai pembayaran).
https://www.googleapis.com/auth/documentsMembuat dan menyunting draft dokumen proyek di Google Docs.
https://www.googleapis.com/auth/driveMembuka, menyimpan, dan menata berkas proyek di Google Drive milik pemilik.
https://www.googleapis.com/auth/gmail.readonlyMembaca informasi Gmail yang diperlukan untuk pekerjaan surat pengantar proyek.
https://www.googleapis.com/auth/gmail.modifyMenyusun dan memperbarui draft surat pengantar proyek di Gmail.
https://www.googleapis.com/auth/gmail.sendMengirim surat pengantar hanya atas perintah eksplisit pemilik.
https://www.googleapis.com/auth/calendarMencatat dan membaca tenggat pekerjaan proyek.
https://www.googleapis.com/auth/contacts.readonlyMengisi nama dan alamat tujuan surat.

The exact scopes configured in Google Cloud must match the scopes actually requested by the application. The owner should remove any scope that is not required by the deployed code; this page is not evidence that an unimplemented feature exists.

2. Di mana data disimpan

Aplikasi ini berjalan di komputer pribadi pemiliknya, bukan di layanan awan. Token akses Google disimpan sebagai berkas lokal di komputer itu dan tidak pernah dikirim ke mana pun. Isi Sheets, Drive, dan email tetap berada di akun Google pemilik — aplikasi membacanya saat dibutuhkan, memprosesnya di komputer lokal, lalu menuliskan hasilnya kembali ke akun yang sama.

3. Dengan siapa data dibagikan

Tidak dengan siapa pun. Data Google tidak dijual, tidak disewakan, tidak dikirim ke pihak ketiga, dan tidak dipakai untuk iklan, profiling, pelatihan model, maupun analitik. Tidak ada layanan pelacak apa pun yang dipasang di aplikasi ini maupun di situs ini.

4. Prinsip Limited Use Google API

Hermes Paljaya hanya menggunakan data Google untuk menyediakan atau meningkatkan fungsi yang dijelaskan di bagian izin di atas. Aplikasi tidak menjual data Google, tidak menggunakannya untuk iklan, credit-worthiness, atau profiling, dan tidak menggunakannya untuk melatih model. Data Google tidak dipindahkan kepada pihak ketiga, kecuali jika diperlukan untuk menyediakan fungsi yang diminta pemilik, diwajibkan oleh hukum, atau sebagai bagian dari merger, akuisisi, atau penjualan aset dengan perlindungan yang setara. Setiap pihak yang menerima data wajib mematuhi pembatasan penggunaan data ini.

Secara khusus, aplikasi tidak menggunakan data Gmail untuk menayangkan iklan, dan tidak membaca, menjual, atau membagikan data untuk tujuan selain fungsi yang dinyatakan. Pernyataan ini mengikuti Google API Services User Data Policy dan persyaratan Limited Use.

5. Berapa lama disimpan

Token akses berlaku sampai dicabut. Hasil olahan sementara disimpan di komputer lokal selama masih dibutuhkan untuk pekerjaan yang berjalan, dan bisa dihapus kapan saja oleh pemiliknya tanpa memengaruhi data di akun Google.

6. Cara menghapus data dan mencabut akses

Karena aplikasi ini tidak memiliki akun pengguna atau server penyimpanan, pemilik dapat menghapus salinan lokal, token OAuth, dan hasil olahan sementara dari komputer tempat aplikasi berjalan. Data yang sudah ditulis ke Google Sheets, Docs, Drive, Gmail, atau Calendar tetap berada di akun Google dan harus dihapus oleh pemilik dari layanan Google tersebut bila memang ingin dihapus.

Pemilik dapat mencabut izin kapan saja lewat Google Account › Aplikasi pihak ketiga, lalu memilih Hermes Paljaya dan memilih Remove access. Pemilik juga dapat menghapus berkas token di komputer lokal. Setelah dicabut, aplikasi tidak dapat memperoleh data baru sampai otorisasi diberikan lagi.

7. Keamanan

Token OAuth dan hasil olahan disimpan sebagai berkas lokal pada komputer pemilik, sesuai dengan uraian di atas. Pemilik bertanggung jawab menjaga keamanan komputer dan akun Google tersebut. Tidak ada jaminan keamanan untuk layanan atau perangkat yang tidak dikendalikan oleh pengembang.

8. Kepatuhan pada kebijakan Google

Penggunaan dan pemindahan data yang diperoleh dari Google API oleh aplikasi ini mengikuti Google API Services User Data Policy, termasuk persyaratan Limited Use.

9. Perubahan

Bila kebijakan ini berubah, tanggal berlakunya di atas ikut diperbarui.

10. Kontak

Pertanyaan soal kebijakan ini, permintaan penghapusan, atau laporan privasi bisa dikirim ke anjas.septian.sunjaya@gmail.com.

In English (summary)

Hermes Paljaya is a single-user personal automation assistant running on its owner's own computer. It accesses only the owner's own Google account, with the owner's own consent, to work with construction-project paperwork stored in that account's Sheets, Docs, Drive, Gmail and Calendar. Google user data is processed locally, is never sold, shared with third parties except as necessary to provide a user-requested function, required by law, or covered by a qualifying business transaction with equivalent protections. It is not used for advertising or profiling, or to train any model; no analytics or tracking is used. OAuth tokens are stored as local files on that computer and are never transmitted elsewhere. Local copies can be deleted, and access can be revoked at any time via Google Account › Third-party apps. This application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
